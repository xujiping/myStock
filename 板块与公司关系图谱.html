📐 数据与使用说明

如何使用

悬停公司/板块节点高亮关联线 · 点击查看右侧详情 · 拖动公司节点可整理布局 · 滚轮缩放图谱、空白处拖动平移 · 搜索可按名称/代码过滤。

编辑与筛选

详情面板提供删除个股与删除单条关系（带确认弹窗）；删除后统计与板块均幅即时重算，点右上角「✕ 重置」可恢复本次会话删除的数据（不会重置拖拽整理的位置）。

图例区可点击关系类型筛选：支持多选，只看选中类型的关系线，无关节点自动淡化；点「全部」恢复。

板块涨跌幅（均幅）

板块节点第二行显示均幅 = 该板块当前关联个股涨跌幅的简单平均（自动剔除已删除公司与无行情个股），红涨绿跌；无可用行情时显示「—」。

如何自定义板块与公司（数据与展示分离）

数据全部来自文件顶部的 DATA 常量，共三张表：groups（板块）、companies（公司）、relations（关系）。 关系以「companyId + groupId + type」描述，一个公司出现多条 relations 即为跨板块。修改后刷新页面即可生效，无需改渲染逻辑。

  1. 加板块：在 groups 里加一条（id 唯一、给一个 color）；
  2. 加公司：在 companies 里加一条（id 唯一、名称、代码、可选备注与来源）；
  3. 建立关系：在 relations 里加一条，type 从 official / invest / report / mapping 中选，分别对应 实线 / 粗实线 / 虚线 / 点线。
DATA = {
  groups:    [ { id:'g1', name:'智谱AI', color:'#2dd4bf', desc:'…' } ],
  companies: [ { id:'huace', name:'华策影视', code:'300133', note:'…' } ],
  relations: [ { companyId:'huace', groupId:'g1', type:'invest', note:'间接入股', source:'澎湃等' } ]
}

行情数据（最新价 / 今日涨跌幅）

行情优先来自腾讯行情公开接口（本地 file:// 打开也可用），失败时自动切换东方财富兜底；页面打开时自动获取，也可点右上角「⟳ 刷新」手动更新。 代码自动识别：6 开头为沪市、其余为深市/北交所、00354.HK 为港股。涨跌幅按 A 股习惯红涨绿跌； 休市时显示最近交易日收盘数据；停牌或无行情的公司显示 —。行情仅供演示参考，不构成投资建议。

⚠ 风险提示

示例数据为 2026-08-02 公开信息整理（沿用「AI概念关系图谱」页来源），仅用于演示页面设计，不构成投资建议。 持股比例口径存在差异，投资前务必以公司公告和定期报告为准；题材股短期波动剧烈，请独立判断。
