# 技术方案

## 运行结构

```text
React/Vite Web
       ↓ /api
Node/Express API
       ↓
MySQL fast-common
       ↑
盘后采集与报告任务
       ↓
reports/YYYY-MM-DD/*.md / *.pdf
```

## 盘后任务

默认流程为：采集行情 → 采集板块 → 拉取公告 → 去重 → 事件分类 → 更新减持状态 → 读取宏观指标 → 计算近期趋势 → 生成 Markdown → 转 PDF → 写入日报索引。

任务必须幂等。相同交易日重复执行时更新同一条行情记录，不重复写入公告和事件。

## 趋势计算

第一版保留 250 个交易日的行情，运行时计算 5/20/60 日收益、均线方向、成交量变化、相对行业表现和回撤。派生指标暂不全部入库，以减少冗余；性能不足时再增加每日信号缓存表。

## 安全

- 数据库账号和密码只从环境变量读取。
- API 不返回数据库密码。
- 外部公告内容保留来源链接和内容哈希。
- 生产环境应限制 MySQL 访问 IP，并开启 TLS。
