# 宏观指标采集 实施计划

## 目标

接入 OMO 利率、A 股主要指数、全球主要指数、美元兑人民币汇率等宏观指标，填充今日总览的宏观天气面板。数据表和前端展示已就绪，只需新增采集脚本和同步任务注册。

## 一、新增采集脚本 `scripts/ingest-macro.py`

**数据源与指标映射**：

| indicator_key | indicator_name | AKShare 接口 | value 字段 | change_pct 来源 |
|---|---|---|---|---|
| `SSE_INDEX` | 上证指数 | `index_zh_a_hist('000001')` | 收盘价 | 涨跌幅列 |
| `SZSE_INDEX` | 深证成指 | `index_zh_a_hist('399001')` | 收盘价 | 涨跌幅列 |
| `CHINEXT_INDEX` | 创业板指 | `index_zh_a_hist('399006')` | 收盘价 | 涨跌幅列 |
| `STAR50_INDEX` | 科创50 | `index_zh_a_hist('000688')` | 收盘价 | 涨跌幅列 |
| `SP500_INDEX` | 标普500 | `index_global_hist_em('标普500')` | 最新价 | 自行计算前日环比 |
| `NASDAQ_INDEX` | 纳斯达克 | `index_global_hist_em('纳斯达克')` | 最新价 | 自行计算前日环比 |
| `NIKKEI225_INDEX` | 日经225 | `index_global_hist_em('日经225')` | 最新价 | 自行计算前日环比 |
| `HSI_INDEX` | 恒生指数 | `index_global_hist_em('恒生指数')` | 最新价 | 自行计算前日环比 |
| `USDCNY` | 美元/人民币 | `currency_boc_sina('美元')` | 央行中间价 | 自行计算前日环比 |
| `FR007` | 7天回购利率 | `repo_rate_query('回购定盘利率')` | FR007 列 | 自行计算前日环比 |

**采集逻辑**：
- 复用 `ingest-announcements.py` 的 `load_env` / pymysql 连接 / `with_retry` / `aero_ingestion_run` 三段式模式
- `task_name = 'macro_indicator'`
- 每类指标独立采集，单个失败不中断整体（记录到 errors）
- A 股指数用最近 7 天日期范围查询取最新行（`index_zh_a_hist` 返回多日，取最后一行）
- 全球指数 `index_global_hist_em` 返回历史序列，取最后两行计算环比
- 汇率 `currency_boc_sina` 取最近 7 天，最后一行为当前值
- 回购利率 `repo_rate_query` 返回历史序列，取最后一行
- 幂等写入：`INSERT ... ON DUPLICATE KEY UPDATE`（主键 `indicator_key + observed_date`）
- `value_text` 对 OMO 利率用文本（如"利率 1.40%"），指数类留空（后端从 value+unit 拼接）
- stdout 输出 `完成：写入 N 条，M 个告警`
- 支持 `--force` 强制覆盖当日已有数据
